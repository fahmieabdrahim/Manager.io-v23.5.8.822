Install Manager.io v23.5.8.822 dalam Android Phone

1. Install Termux

Install Termux melalui Google Play Store:

Google Play – Termux

Update Termux

pkg update -y && pkg upgrade -y

Install keperluan

pkg install -y proot-distro wget tar ca-certificates

2. Install Debian

Install Debian

proot-distro install debian

Masuk ke Debian

proot-distro login debian

Install dependencies

apt update && apt install -y wget tar ca-certificates libicu-dev curl

3. Install Manager.io Server

Versi Manager.io yang digunakan: 23.5.8.822

Release rasmi: Manager.io v23.5.8.822

Cipta folder Manager

mkdir -p /root/manager && cd /root/manager

Download Manager Server ARM64

wget -O ManagerServer-linux-arm64.tar.gz https://github.com/Manager-io/Manager/releases/download/23.5.8.822/ManagerServer-Linux-arm64.tar.gz

Extract fail

tar -xzf ManagerServer-linux-arm64.tar.gz

Beri permission

chmod +x ManagerServer

Jalankan Manager.io Server

./ManagerServer --urls http://*:8080
Penting: Jangan tutup Termux atau Debian ketika Manager.io sedang digunakan.

Buka Manager pada Android

http://127.0.0.1:8080

4. Share kepada iPad / Telefon Lain

Hidupkan Mobile Hotspot

Hidupkan Mobile Hotspot pada Android Phone.

Sambungkan iPad atau telefon lain kepada hotspot tersebut.

Cari IP Address Android

ifconfig

Cari bahagian: 

swlan0
inet 10.xxx.xxx.xxx

Contoh IP: 

10.253.113.26

Buka pada iPad / Telefon Lain

Gunakan IP Android tersebut dan tambah port 8080. 

http://10.253.113.26:8080
Nota: IP 10.253.113.26 hanyalah contoh. Gunakan IP yang dipaparkan pada Android Phone anda.

5. Matikan Manager.io Server

Untuk hentikan Manager.io Server:

Tekan: Ctrl + C

Kemudian keluar dari Debian: 

exit

Selepas itu, Mobile Hotspot boleh dimatikan.
